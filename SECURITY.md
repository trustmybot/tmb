# Security policy

## Report a vulnerability

Please do not report security problems in public issues, pull requests or discussions.

Report them privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability**, or go straight to [the private report form](https://github.com/trustmybot/tmb/security/advisories/new). Only the maintainers can see the report.

Include what you can of:

- the version (`tmb --version`) and your OS;
- what the problem lets someone do;
- the steps to reproduce it.

We will confirm we got the report, keep you told of progress, and credit you in the advisory unless you would rather not be named.

## Supported versions

Fixes go into the newest release of each channel. Older releases do not get fixes: run `tmb update` to get the newest one.
