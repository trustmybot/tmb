# Reporting a tmb bug

When a tmb tool or command fails in a way that is tmb's fault, not the project's, you may offer a bug report for tmb's maintainers.

1. Draft it with `feedback_draft`. When it is refused because the feedback program is off, don't offer a report; the Human can still run `tmb feedback`.
2. Show the Human the whole report word for word and where it goes: it becomes a public issue.
3. Offer to change the sentence on what was being done, and draft again with their words.
4. Send it with `feedback_send` only after their yes to that draft. On a no, or no answer, send nothing.

Never put source code, file contents, prompts or anyone's messages in a report: it is public.
