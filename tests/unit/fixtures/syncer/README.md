# Recorded answers for the syncer's reader

Each `.txt` is what `gh api --include` printed, trimmed to the headers and fields the reader uses.

- `issues`, `comments`, `review`, `pulls`, `ms`, `not-modified`, `not-found`: recorded from GitHub on 2026-11-26.
- `rate-limited-primary`, `rate-limited-secondary`: written from GitHub's rate limit docs, because a limit cannot be recorded on demand.
